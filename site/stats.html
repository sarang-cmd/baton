        What this counts, and what it cannot. A row is written when the page asks the server to count a download, so a download taken straight from the GitHub releases page or by an automated fetcher is not in this table. Unique addresses are counted by distinct address, so one person on a changing connection can look like two, and a shared office connection can look like one. The ten second window means a double click counts once. Countries are whatever the edge resolved, which is often empty. Nothing here is sold, shared, or joined to an account, because there are no accounts.
