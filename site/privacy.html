Privacy

Applies to the browser extension and this website. Last updated 16 November 2026.

This extension exists to send the word "continue". That job does not require collecting anything about you, so it does not. This page describes the small amount of data that stays on your own computer, and confirms what never leaves it.

What the extension stores

One record in your browser's local extension storage. It contains your settings (whether auto-send is on, the delay, the message text, the safety cap, and the guard switches) and a counter of how many messages have been sent in this session. You can clear it by removing the extension, and nothing is written to disk outside that storage area.

What the extension can see

The extension is granted access to pages on arena.ai only, because that is where the banner appears. On those pages it reads text in order to answer one question: is the tool-call limit banner on screen? It also reads whether the message box is empty before typing into it.

Text from your conversations is not copied, stored, logged, or transmitted. It is inspected in place and discarded immediately.

What never happens

  • Nothing about your conversations, your account, or the pages you read is sent anywhere.
  • No analytics, telemetry, crash reporting, advertising, or fingerprinting.
  • No account, sign-in, licence key, or payment.
  • No remote code. Everything that runs is in the files you installed.
  • No reading of other tabs, browsing history, bookmarks, or downloads.

Permissions, in plain language

  • storage keeps your settings and the send counter on your machine.
  • activeTab lets settings ask the current arena.ai tab for its status while the settings view is open.
  • Host access to arena.ai is what allows the script to see the banner and fill the message box.
  • Host access to baton-arena.vercel.app is what lets the settings page ask whether a newer release exists, and lets it download that release into a folder you picked.

What the extension sends now

Up to version 1.6 it sent nothing at all. From 1.7 there are exactly two requests, both to this project's own site and never to arena.ai:

  • When you open the settings page, at most once every twelve hours, it asks for the newest version number. That answer is cached on your machine.
  • At most once a day it sends one line saying which version is installed, so the download counter can tell how many installs exist. It carries the version number, the word extension, and nothing else. No identifier is created, stored, or reused, so this line cannot follow you between visits.

Both requests are counted by the site the same way a download is, which brings us to the next section. Neither request is made from arena.ai pages, and neither goes anywhere else.

This website

The pages are static files with no cookies, no analytics, no advertising and no third-party embeds. Fonts are taken from your operating system, so nothing calls out to a font service.

One thing is counted. When someone takes a download, and once a day when an installed extension checks in, the site writes a row to its own database. That row holds:

  • the version, the channel (site, GitHub, or update), and which button was pressed;
  • the IP address the request came from;
  • the two-letter country your browser's request was routed through, which the hosting edge already knows;
  • the browser family (Chrome, Edge, Firefox, and so on), not the full user agent string;
  • the time.

The address is stored in full, and it is stored so that the counter can say how many distinct people downloaded rather than how many clicks happened. It is not joined to any account, because there are no accounts. It is not shared, sold, or sent to anyone. It is not used to track you across other sites, and the site sets no cookie that would make that possible. Rows are kept indefinitely so the history stays readable; ask on the issue tracker and they will be deleted.

Nothing is counted if you use a content blocker that stops the request, or if you download straight from GitHub instead of this site. The extension's settings work the same either way.

Changes

If a future version ever changes any of the above, this page will be updated before that version is released, and the change will be noted in the release notes.
